# Circular Innovation Hub (CIH)

**Home of Circular Economy Excellence in Africa.**

Circular Innovation Hub (CIH) is a one-stop-shop designed to inspire and enable the transition to a sustainable world. We fast-track the development towards a more circular society by providing a collaborative platform where stakeholders can grow, meet, influence, and be seen.

## Our Mission & Vision

- **Mission**: To be an active part of fast-tracking the development towards a more circular and sustainable society by creating a collaborative platform for innovation.
- **Vision**: A world where circular economy principles drive prosperity, protect our planet, and empower communities across Africa and beyond.

## Key Offerings

### 1. Accelerator Program

We walk with entrepreneurs from idea generation to scale-up, connecting them with mentors, partners, opportunities, and investors.

### 2. Co-working & Events

A conducive environment for office space, conferences, and networking events, featuring a spacious garden and modern facilities.

### 3. Corporate Training

A sustainability toolkit designed to help corporate entities transition towards the circular economy and reduce their carbon footprint.

### 4. Advisory Services

Expert guidance on circular economy strategies, impact measurement, and sustainable business model transformation.

### 5. CIH Academy

Specialized training and educational programs focused on green skills and circular economy principles.

## Our Impact

- **85%** Waste diverted from landfills through our programs.
- **50K+** Entrepreneurs empowered across the continent.
- **$15M+** Circular economy investments facilitated.
- **26+** Employment opportunities created (direct & indirect).

## Technical Stack

This project is built using modern web technologies:

- **Frontend**: [React](https://reactjs.org/) (with TypeScript)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router](https://reactrouter.com/)

## Getting Started

To run this project locally:

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
